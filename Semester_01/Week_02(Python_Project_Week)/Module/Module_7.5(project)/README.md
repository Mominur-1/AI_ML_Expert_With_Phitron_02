## 🎯 AI Code Debugger
🐞 AI-Powered Bug Detection & Fix Generator from code screenshots

## 🚀 Live App & Code
**Live**: [ai-code-fix.streamlit.app](https://ai-code-fix.streamlit.app/)
**Repo**: [github.com/Mominur-1/AI_code_debugger](https://github.com/Mominur-1/AI_code_debugger)

## ✨ Features
✅ Upload a screenshot of buggy code
✅ Get AI-generated hints to find the bug yourself
✅ Get full error explanation + corrected code
✅ Clean, spinner-based loading while Gemini analyzes your code

## 🛠️ Tech Stack
Streamlit • Google Gemini AI • python-dotenv • Python

## 🚀 Quick Start

pip install -r requirements.txt
streamlit run app.py

Set your API key:

GEMINI_API_KEY=your_api_key_here
